# Patches do upstream

Vazio de propósito.

Se um dia for inevitável alterar um arquivo do FusionPBX, o patch vem para cá —
pequeno, isolado e aplicado no deploy. Assim continua dando para atualizar o
upstream com `git pull`, o que um fork da árvore inteira impediria.

Antes de acrescentar um patch, verificar se dá para resolver dentro do nosso app
em `../app/simplificaja_api/`.
